# Screenshot manifest

Generated by `scripts/capture_demo.py` in the source repository.

Every image below is a real page from the running application. The harness starts the API against a
throwaway database, seeds content **through the public HTTP API**, starts the Next.js console, and
then signs in through the actual login form with a real browser before capturing. If any page
rendered an error screen, redirected to `/login`, or was missing its expected content marker, the
harness failed instead of writing the file.

Nothing here is a mockup, and no UI state was faked.

| File | Route | Shows |
| ---- | ----- | ----- |
| `01-overview.png` | `/` | Operations overview: call metrics, component health, hardware profile and the capability matrix. Health reads `degraded` with the exact reasons; unmeasured metrics read `— Not measured`, not `0`. |
| `02-agents.png` | `/agents` | Six configured agents across German, Albanian and English, each showing published versus draft state, plus the 25-template catalogue. |
| `03-agent-new.png` | `/agents/new` | The create-agent form: template picker, per-language support (Deutsch / Shqip / English), Albanian variant, address form, and toggles for mid-call language switching and AI disclosure. |
| `04-calls.png` | `/calls` | Call history and latency percentiles. Undefined percentiles render as `—`, never `0`. |
| `05-knowledge.png` | `/knowledge` | Retrieval bases used for grounding, with chunk counts and reindexing. |
| `06-contacts.png` | `/contacts` | The contact list and the do-not-call register — the suppression list checked before every outbound dial. |
| `07-providers.png` | `/providers` | The model catalogue and licence audit: 24 known models with licence and commercial position, 7 permitted, 7 refused, 17 requiring attribution. |
| `08-tools.png` | `/tools` | The tool catalogue: 215 declared, 39 implemented, 176 declared only. |
| `09-system.png` | `/system` | Runtime state, organisation settings, members, roles and the audit trail. |

## Reproduction

From the source repository:

```bash
python scripts/capture_demo.py
```

The scratch database is deleted and the servers stopped when it finishes.
